Runtime and ownership

DomSculptor

A runtime owns a scheduler, a scope stack, and an element registry. Create one per application, or several when interfaces need isolated flushing and diagnostics. Everything created through a runtime has an owner, so nothing needs manual cleanup that the runtime cannot do for you.

DomSculptor

createDetached<K extends string>(tag: K, callback?: ((element: DomElement<ElementForTag<K>>) => void) | null): DomElement<ElementForTag<K>>

Creates an element that is not in the document. Nothing appears until you mount it, which lets you build and configure a subtree in one pass and pay a single insertion.

tagNameAny tag name. TypeScript infers the native element type from it.
callbackOptional. Receives the element before it is returned.

Returns. The new DomElement.

let card = sculptor.createDetached('article', el => el.class.add('card'));
card.child.create('h2').setText('Offline first');
sculptor.mount(card, '#app');       // one insertion, fully built

create<K extends string>(tag: K, callback?: ((element: DomElement<ElementForTag<K>>) => void) | null): DomElement<ElementForTag<K>>

Creates an element and mounts it immediately when a parent is given. Without a parent it behaves exactly like createDetached.

tagNameThe tag to create.
parentOptional selector, native Node, or DomElement.
callbackOptional configuration callback.

Returns. The new DomElement.

Throws. TypeError if a selector matches nothing, or if the parent is disposed.

let button = sculptor.create('button', '#toolbar', el => el.setText('Save'));

createIn<K extends string>(parent: string | Node | DomElement, tag: K, callback?: ((element: DomElement<ElementForTag<K>>) => void) | null): DomElement<ElementForTag<K>>

Creates an element inside a parent you already hold. The argument order mirrors the nesting.

Returns. The new child DomElement.

let list = sculptor.create('ul', '#app');
let row = sculptor.createIn(list, 'li');

createProgressively<K extends string>(tag: K, parent: string | Node | DomElement, callback?: ((element: DomElement<ElementForTag<K>>) => void) | null): DomElement<ElementForTag<K>>

Mounts the first element immediately and one more per animation frame after that, so a large render does not block interaction. The element is returned configured straight away; only its insertion is deferred.

Returns. The new DomElement, already configured.

for (let row of thousands) {
    sculptor.createProgressively('div', container, el => el.setText(row.label));
}
// sculptor.rendering === true until the queue drains

rendering reports whether queued work remains. Disposing the parent cancels whatever is still queued.

mount<T extends DomElement | ComponentInstance>(element: T, parent: string | Node | DomElement): T

Attaches an element or component instance to a parent. Mounting an element that is already mounted moves it rather than duplicating it.

Returns. The mounted element or instance.

Throws. TypeError when the parent cannot be resolved or has been disposed.

sculptor.mount(view, '#app');
sculptor.mount(view, otherParent);   // moves it; no duplicate

tryMount<T extends DomElement | ComponentInstance>(element: T, parent: string | Node | DomElement): T | null

The non-throwing form of mount, for parents that may not exist yet.

Returns. The mounted value, or null when the parent could not be resolved.

if (!sculptor.tryMount(banner, '#optional-slot')) {
    // the slot is not on this page
}

unmount<T extends DomElement | ComponentInstance>(element: T): T

Detaches without disposing. The element keeps its listeners, bindings, and children and can be mounted again. Unmount hooks run child-first; mount hooks do not run again on a later mount.

sculptor.unmount(panel);      // reversible
sculptor.mount(panel, '#app');

wrap(selectorOrNode: string | Node): DomElement

Takes over an existing node so the library can manage it. One wrapper exists per node, so wrapping the same node twice returns the same object.

Returns. The DomElement for that node.

Throws. TypeError when a selector matches nothing.

let form = sculptor.wrap('#signup');
form.on('submit', event => event.preventDefault());

A wrapped node is not deleted by sculptor.dispose() — the runtime did not create it, so it only releases the listeners and bindings it added.

tryWrap(selectorOrNode: string | Node): DomElement | null

The non-throwing form of wrap.

Returns. The DomElement, or null when nothing matched.

adopt<T extends Node>(node: T): DomElement<T>

Takes ownership of a node you already have a reference to, without a selector lookup.

Returns. The DomElement for that node.

tree<K extends string>(config: TreeConfig<K>): DomElement<ElementForTag<K>>

Builds a detached hierarchy from a plain configuration object. Text is written as text nodes, never parsed, and attributes, class, and children all accept reactive values.

Returns. The root DomElement.

Throws. TypeError for a missing tag or an invalid class, attributes, on, or ref.

let refs = {};
let panel = sculptor.tree({
    tag: 'section',
    refs,
    class: { panel: true, 'is-busy': busy },
    children: [
        { tag: 'h2', ref: 'title', text: heading },
        { tag: 'button', text: 'Save', attributes: { disabled: busy },
          on: { click: save } }
    ]
});
refs.title.class.add('lead');

when(condition: Readable<unknown>, branch: DomChild | (() => DomChild), options?: { fallback?: DomChild | (() => DomChild); preserve?: boolean; disposeOnStop?: boolean; parent?: string | Node | DomElement; }): Unsubscribe

Mounts one of two branches according to a condition, in a single queued pass. Factory branches are disposed when they leave unless preserve is set.

Returns. A stop function that releases the region.

Throws. TypeError without a readable condition, or when no parent can be determined.

let stop = sculptor.when(loggedIn,
    () => sculptor.tree({ tag: 'p', text: 'Welcome back' }),
    { parent: '#app', fallback: () => sculptor.tree({ tag: 'a', text: 'Sign in' }) }
);
stop();   // releases the region and its ownership entry

signal<T>(initial: T): State<T>

Creates a signal: a value plus change notification. Reads are synchronous; DOM bindings are queued into one pass per frame.

Returns. A State.

let count = sculptor.signal(0);
count.get();          // 0
count.set(1);
count.update(n => n + 1);

state<T>(initial: T): State<T>

An alias for signal, kept for readability where the value is a record rather than a scalar.

computed<T>(compute: () => T, dependencies?: readonly Readable<unknown>[]): Computed<T>

A value derived from other signals. With no dependency list it discovers what it reads on every run, so a branch that stops reading a signal stops depending on it.

computeFunction producing the value.
dependenciesOmit to track automatically. An array pins dependencies. [] evaluates once.

Returns. A Computed.

Throws. TypeError for an invalid dependency list; Error on a read cycle.

let total = sculptor.computed(() => items.get().length);
let pinned = sculptor.computed(() => expensive(), []);   // evaluated once

Tracking is synchronous: a signal read after an await is not discovered.

effect(run: () => void | (() => void), dependencies?: readonly Readable<unknown>[]): Unsubscribe

Runs immediately, then again whenever a signal it read changes. Returning a function registers cleanup, which runs before each rerun and once when the effect stops.

Returns. A stop function.

let stop = sculptor.effect(() => {
    document.title = title.get();
    return () => console.log('cleaning up');
});

An arrow with an implicit return hands its value back as a cleanup, so write () => { read(); } rather than () => read().

batch<T>(callback: () => T): T

Groups writes so the DOM updates once at the end. Nested batches defer until the outermost completes.

sculptor.batch(() => {
    first.set('Grace');
    last.set('Hopper');
});   // one rendering pass

flush(): void

Applies queued DOM work immediately instead of waiting for the scheduled pass. Useful in tests and when measuring layout.

value.set('next');
sculptor.flush();
element.html.textContent;   // already 'next'

store<T extends Record<string, unknown>>(initial: T): DataStore<T>

Creates a keyed store. An alias for data.

data<T extends Record<string, unknown>>(initial: T): DataStore<T>

Creates an object whose keys are independently observable, with a signal available per key.

Returns. A DataStore.

let profile = sculptor.data({ name: 'Ada', theme: 'dark' });
profile.set('theme', 'light');
profile.signal('theme').bindText(label);

asyncState<T = unknown>(initialData?: T | null): AsyncState<T>

Tracks status, data, and error for asynchronous work, aborting a superseded run by default.

Returns. An AsyncState.

let users = sculptor.asyncState([]);
let { status, data, error } = await users.run(({ signal }) =>
    fetch('/api/users', { signal }).then(r => r.json())
);

component<P extends object = Record<string, never>, A extends object = Record<string, never>>( factory: (props: P, context: Context) => ComponentResult<A>, options?: { name?: string } ): ComponentFactory<P, A>

Wraps a factory so each invocation gets its own disposal scope. Everything created inside is released when the instance is disposed.

factoryReceives (props, context) and returns a root or a { root, api?, dispose? } definition.
optionsname improves diagnostics.

Returns. A factory function producing a ComponentInstance.

let Counter = sculptor.component(({ start = 0 }) => {
    let count = sculptor.signal(start);
    let root = sculptor.tree({ tag: 'button', text: sculptor.computed(() => String(count.get())) });
    root.on('click', () => count.update(n => n + 1));
    return { root, api: { reset: () => count.set(start) } };
}, { name: 'Counter' });

let counter = Counter({ start: 5 });
sculptor.mount(counter, '#app');
counter.api.reset();
counter.dispose();

errorBoundary<P extends object, A extends object>( componentFactory: ComponentFactory<P, A>, fallback: (error: unknown, props: P, context: Context) => ComponentResult<A> | ComponentInstance<A> ): ComponentFactory<P, A>

Wraps a component factory so a failure during creation renders a fallback instead of propagating. The failed scope is disposed before the fallback is built.

Returns. A factory producing either the component or the fallback.

let Safe = sculptor.errorBoundary(Risky, error =>
    sculptor.tree({ tag: 'p', text: 'Could not load this panel' })
);

createScope(): DisposalScope

Creates an ownership scope. Anything created inside scope.run() belongs to it and is released together, in reverse order of creation.

Returns. A DisposalScope.

let scope = sculptor.createScope();
scope.run(() => {
    let value = sculptor.signal(0);
    value.subscribe(render);     // released with the scope
});
scope.dispose();

createContext(parent?: Context | null, initial?: Map<symbol, unknown> | Record<PropertyKey, unknown> | null): Context

Creates a context, optionally inheriting from a parent and seeded with an object or Map.

Returns. A Context.

createContextKey<T = unknown>(description?: string): ContextKey<T>

Creates a unique symbol key, so two features can use the same name without colliding.

Returns. A symbol.

router(routes: Record<string, RouteView>, options?: RouterOptions): Router

Maps path patterns to views and keeps one mounted. Patterns support :name segments and a * catch-all; literal segments are escaped, so /a.b matches only /a.b. Each view runs in its own scope, disposed on the way out.

routesAn object of pattern to view function.
optionsparent selects the outlet; hash: true routes on the fragment.

Returns. A Router.

Throws. TypeError when routes are missing or a view is not a function.

let router = sculptor.router({
    '/': () => Home(),
    '/posts/:slug': ({ params, scope }) => Post({ slug: params.slug, scope }),
    '*': () => sculptor.tree({ tag: 'p', text: 'Not found' })
}, { parent: '#app', hash: true });

router.navigate('/posts/hello');

* is a whole-path wildcard: a route of '*' puts the entire path in params.rest including its leading slash, while '/*' captures only the remainder.

virtualList<T>(items: readonly T[], container: DomElement, options: VirtualListOptions<T>): DomElement

Renders a large collection by mounting only the visible range plus overscan. A spacer of the full collection height keeps the scrollbar representing every record.

itemsThe collection. Copied, so later mutation of your array does not affect the list.
containerA scrollable DomElement, not already virtualized.
optionsSee VirtualListOptions.

Returns. The container.

Throws. TypeError for a missing rowHeight or render, or duplicate keys; Error if the container is already virtualized.

let list = sculptor.create('div', '#app')
    .setStyle({ height: '600px', overflow: 'auto' });

sculptor.virtualList(records, list, {
    rowHeight: 48,
    overscan: 6,
    key: record => record.id,
    render: record => sculptor.createDetached('div').setText(record.name)
});
// 9,000 records, roughly 20-60 rows in the DOM

A row holding the focused element is kept mounted outside the visible range and is not updated while it holds focus, so scrolling cannot pull an input out from under someone typing.

updateVirtualList<T>(container: DomElement, items: readonly T[]): DomElement

Replaces the collection, resizing the spacer and clamping a scroll position left past the new end. Rows for surviving keys are reused.

Returns. The container.

Throws. TypeError on duplicate keys, before any DOM change.

scrollVirtualList(container: DomElement, index: number, options?: VirtualScrollOptions): boolean

Scrolls to an index or to { key }, with start, center, end, or nearest alignment.

Returns. true when the target was reachable, false otherwise.

sculptor.scrollVirtualList(list, 5000, { align: 'center' });
sculptor.scrollVirtualList(list, { key: 'user-42', align: 'nearest' });

virtualListStatus(container: DomElement): VirtualListStatus | null

Reads the current range as a frozen snapshot, for tests and diagnostics.

Returns. A VirtualListStatus, or null when the container is not virtualized.

disposeVirtualList(container: DomElement): DomElement

Removes virtualization and every mounted row while keeping the container, which can then be virtualized again.

Returns. The container.

readonly rendering: boolean

Whether queued progressive creation or virtual-list work remains. One status path covers both.

dispose(): void

Releases everything the runtime owns: scheduled work, signals, effects, stores, and the elements it created. Idempotent. Nodes taken over with wrap or adopt stay in the document; only their listeners and bindings are released.

sculptor.dispose();
sculptor.disposed;   // true

readonly disposed: boolean

Whether the runtime has been disposed.

DomSculptorOptions

development?: boolean

Enables structured diagnostics. Leave it off in production; the checks are skipped entirely when disabled.

onWarning?: (warning: DevelopmentWarning) => void

Receives every diagnostic instead of the console, which makes them assertable in tests.

let warnings = [];
let sculptor = new DomSculptor({ development: true, onWarning: w => warnings.push(w.code) });

DevDomSculptor

reportLeaks(): number

Counts component scopes that are still active, for use at the end of a test.

Returns. The number of undisposed component scopes.

DevelopmentWarning

code: string

A stable identifier such as duplicate-list-key or disposed-element-operation, safe to assert on.

message: string

A human-readable explanation.

details?: unknown

The offending value, when there is one.

Elements

DomElement

A thin, owned wrapper around one native node. Mutating methods return the same wrapper so calls chain; html is the escape hatch to the node itself.

DomElement

html: T | null

The native node. Becomes null once disposed, which is the cheapest way to ask whether a wrapper is still alive.

element.html.scrollIntoView();
if (!element.html) return;   // disposed

readonly children: readonly DomElement[]

A frozen snapshot of the owned children, so iterating it cannot be disturbed by changes made while you iterate.

Returns. A frozen array of DomElement.

attribute: DomAttributes

Attribute operations. See DomAttributes.

class: DomClasses

Class-list operations. See DomClasses.

child: DomChildren

Child operations that keep the DOM and ownership in step. See DomChildren.

setText(text: unknown): this

Replaces all content with a single text node. Markup is never parsed, so untrusted text is safe here.

Returns. The same element, for chaining.

element.setText('<img src=x onerror=alert(1)>');
// renders those characters; nothing is executed

text<V>(readable: Readable<V>): this

Binds a readable to a dedicated text node, so updates do not disturb sibling content.

Returns. The same element.

Throws. TypeError unless given something with get and subscribe.

let name = sculptor.signal('Ada');
sculptor.create('p', '#app').text(name);
name.set('Grace');   // only the text node changes

attr<V>(name: string, readable: Readable<V>): this

Binds an attribute to a readable. null, undefined, and false remove the attribute; true writes an empty value.

Returns. The same element.

button.attr('disabled', busy);       // present only while busy is truthy
input.attr('aria-invalid', invalid);

classToggle<V>(name: string, readable: Readable<V>): this

Adds or removes a class from a readable, or several at once from a map. Plain booleans are accepted alongside signals.

Returns. The same element.

row.classToggle('selected', isSelected);
row.classToggle({
    'btn-primary': favourited,
    'btn-outline-primary': sculptor.computed(() => !favourited.get()),
    btn: true
});

setStyle(property: string | Record<string, unknown>, value?: unknown): this

Sets one inline style property, or several from an object.

Returns. The same element.

panel.setStyle('color', 'rebeccapurple');
panel.setStyle({ height: '600px', overflow: 'auto' });

styleValue<V>(name: string, readable: Readable<V>): this

Binds one style property to a readable. null clears the property rather than writing the word.

Returns. The same element.

getValue(): unknown

on<K extends keyof GlobalEventHandlersEventMap>( event: K, callback: (event: GlobalEventHandlersEventMap[K]) => void, options?: AddEventListenerOptions | boolean ): this

Adds a listener, or delegates when given a selector between the event name and the handler. A delegated handler receives (event, matchedElement) and matches only inside this element, so one listener serves rows that do not exist yet.

Returns. The same element.

Throws. TypeError for invalid arguments, or if the element is disposed.

button.on('click', () => save());
button.on({ focus: onFocus, blur: onBlur });

// one listener for every row, now and later
list.on('click', 'a.remove', (event, link) => remove(link.dataset.id));

once<K extends keyof GlobalEventHandlersEventMap>( event: K, callback: (event: GlobalEventHandlersEventMap[K]) => void, options?: AddEventListenerOptions | boolean ): this

Adds a listener that detaches before it is invoked, so a handler cannot re-arm itself.

Returns. The same element.

off(event: string, callback?: EventListener | null): this

Removes a listener by handler, or every listener for an event when the handler is omitted. Delegated handlers are removed by the same function you passed in.

Returns. The same element.

onMount(callback: (element: this) => void): this

Runs once when the element first becomes connected — immediately if it already is. It does not run again on a later mount.

Returns. The same element.

onUnmount(callback: (element: this) => void): this

Runs on every explicit unmount, child before parent.

Returns. The same element.

onDispose(callback: (element: this) => void): this

Runs once during permanent cleanup, child before parent.

Returns. The same element.

Disposal detaches the node before tearing the subtree down, so a hook sees the subtree already out of the document; only the element disposal started at has a null parentNode. Read an element's position before disposing it, not from the hook.

onRemove(callback: (element: this) => void): this

A compatibility alias for onDispose.

Returns. The same element.

remove(): void

A compatibility alias for dispose.

dispose(): void

Permanently releases the element: its node, listeners, bindings, children, and its entry in the runtime's ownership set. Idempotent, and safe to call from inside a hook.

element.dispose();
element.html;         // null
element.setText('x'); // throws: the element has been disposed

append(child: DomChild): DomElement

Appends a DomElement, native node, or string, keeping the DOM and ownership in step. It returns the element that was added, so a structure can be built downwards without a temporary variable per level; a raw node or string returns the container instead, because there is no wrapper to return.

Reactive state

Signals, computed values, and bindings

A signal holds a value and notifies on change. Bindings connect one to the DOM and release themselves with the element they wrote into.

State

set(next: T): void

Writes a new value and notifies. A write equal to the current value by Object.is does nothing, so NaN is not treated as a change. Writes made inside a subscriber are queued so every subscriber sees the same order.

Throws. Error if the signal is disposed.

count.set(1);
count.set(1);   // no notification: equal by Object.is

update(updater: (value: T) => T): void

Writes a value derived from the current one.

Throws. TypeError without a function.

count.update(n => n + 1);
items.update(list => list.filter(item => item.id !== id));

bind<E extends Node>(element: DomElement<E>, updater?: ((value: T, element: DomElement<E>) => void) | FormBindingOptions<T, E>): DomElement<E>

The general binding. Given a function it runs on every change with (value, element); given an options object it behaves as sync. The binding is released when the element is disposed.

Returns. The element.

progress.bind(bar, (value, el) => el.setStyle('width', value + '%'));

sync<E extends Node>(element: DomElement<E>, options?: FormBindingOptions<T, E> | ((value: unknown, element: E) => T)): DomElement<E>

Two-way form binding. Writes the signal into the control and the control back into the signal, normalising checkboxes, radio groups, numbers, multiple selects, and IME composition.

elementThe control.
optionsA parser function, or FormBindingOptions.

Returns. The element.

name.sync(input);
quantity.sync(numberInput, { parse: Number });
tags.sync(checkbox, { group: true });

list<K>(container: DomElement, options: KeyedListOptions<T extends readonly (infer I)[] ? I : never, K>): DomElement

Renders an array into a container. The keyed form preserves element identity across reorders, so focus, scroll position, and uncontrolled input survive; the simple form replaces all rows and suits data with no stable identity.

containerThe container element, whose children the list owns.
renderFnA render function, or KeyedListOptions.

Returns. The container.

Throws. TypeError for duplicate keys — raised before any DOM change, so a rejected update leaves the list intact.

rows.list(list, {
    key: row => row.id,
    render: row => sculptor.tree({ tag: 'li', text: row.label }),
    update: (element, row) => element.setText(row.label)
});

Reorders move the minimum number of nodes: rows whose relative order has not changed stay where they are.

bindVisible(element: DomElement, transform?: (value: T) => boolean): DomElement

Shows the element while the value is truthy, hiding it otherwise, through show() and hide().

Returns. The current value.

subscribe(callback: (value: T) => void, options?: SubscriptionOptions): Unsubscribe

Calls back on every change until unsubscribed. A subscription made inside a scope belongs to that scope and is released with it; outside a scope, the returned function is yours to call.

callbackReceives the new value.
optionsimmediate delivers the current value at once; signal unsubscribes on abort.

Returns. An unsubscribe function.

Throws. TypeError without a function, or if the signal is disposed.

let stop = total.subscribe(value => console.log(value), { immediate: true });
stop();

SubscriptionOptions

immediate?: boolean

Deliver the current value to the callback as soon as it subscribes.

signal?: AbortSignal

An AbortSignal; aborting unsubscribes. An already-aborted signal never subscribes.

KeyedListOptions

key(item: T, index: number): K

Returns a stable identity per item. Identity is what lets a row keep its node across a reorder. Duplicates are rejected before the DOM is touched.

render(item: T, index: number): DomElement

Builds a row. Called once per new key; must return a live DomElement.

update?(element: DomElement, item: T, index: number): void

Applies changed data to a row that already exists. Keyed rows are reused, so anything applied in render that depends on the item must be reapplied here — or bound to a signal, which cannot go stale.

FormBindingOptions

event?: string

The DOM event that writes back. Defaults to input for text and change for the rest.

parse?: (value: unknown, element: E) => T

Converts the raw control value before it reaches the signal. Ignored when get is supplied, because a custom read already returns the value the signal should hold.

get?: (element: E) => T

Replaces the entire read, including parse. Receives the native node, not the wrapper.

picked.sync(control, {
    get: node => node.dataset.value,
    set: (node, value) => { node.dataset.value = value; }
});

set?: (element: E, value: T) => void

Replaces the entire write. Receives the native node.

group?: boolean

Treats a checkbox as part of a group whose signal holds an array of the checked values.

multiple?: boolean

Treats a select as multiple, so the signal holds an array.

Keyed state

Stores

A store is an object of independently observable keys, with a signal available per key when you want to bind one field.

DataStore

get(): T

Reads one key, or the whole record when called with no argument.

Returns. The value for the key, or a snapshot of every key.

profile.get('theme');   // 'dark'
profile.get();          // { name: 'Ada', theme: 'dark' }

set<K extends keyof T>(key: K, value: T[K]): this

Writes one key, or several from an object. Each key notifies independently, so a binding on one field is not woken by a change to another.

Returns. The store.

profile.set('theme', 'light');
profile.set({ name: 'Grace', theme: 'dark' });

update<K extends keyof T>(key: K, updater: (value: T[K]) => T[K]): this

Writes one key from its current value.

Returns. The store.

Throws. TypeError without an updater function.

cart.update('count', n => n + 1);

has(key: PropertyKey): boolean

Whether a key is present.

Returns. boolean.

delete(key: keyof T): boolean

Removes a key, notifying its observers with undefined. Listeners stay attached, so they fire again if the key is set later.

Returns. boolean, whether the key existed.

signal<K extends keyof T>(key: K): State<T[K]>

A readable for one key, so a single field can be bound without re-rendering anything else.

Returns. A readable signal for that key.

profile.signal('theme').bindText(themeLabel);

onChange<K extends keyof T>( key: K, callback: (value: T[K], previous: T[K] | undefined, key: K) => void, options?: SubscriptionOptions ): Unsubscribe

Observes one key. Accepts an AbortSignal to stop observing.

Returns. An unsubscribe function.

onAnyChange( callback: <K extends keyof T>(key: K, value: T[K], previous: T[K] | undefined) => void, options?: SubscriptionOptions ): Unsubscribe

Observes every key, receiving (key, value, previous).

Returns. An unsubscribe function.

offChange<K extends keyof T>(key: K, callback?: ((value: T[K]) => void) | null): this

Removes an observer by key and callback.

dispose(): void

Releases the store, its per-key signals, and every observer.

readonly disposed: boolean

Whether the store has been disposed.

Asynchronous work

Async state

Status, data, and error in one snapshot, with cancellation built in. Runs never reject: the snapshot is the result.

AsyncState

run<R extends T = T>( task: (context: { signal: AbortSignal }) => Promise<R> | R, options?: { abortPrevious?: boolean } ): Promise<AsyncSnapshot<T>>

Runs a task, moving through loading (or refreshing when data is already held) to success or error. A later run aborts the earlier one by default, and a superseded result can never overwrite a newer one.

taskReceives { signal } to pass to fetch or any abortable work.
optionsabortPrevious: false lets runs overlap.

Returns. A promise resolving to the resulting snapshot. It never rejects — read error.

let { status, data, error } = await users.run(({ signal }) =>
    fetch('/api/users', { signal }).then(response => response.json())
);
if (status === 'error') report(error);

retry(): Promise<AsyncSnapshot<T>>

Runs the previous task again.

Returns. A promise resolving to the resulting snapshot.

cancel(): void

Aborts work in flight and returns to idle, or to success when data is already held.

reset(): void

Aborts work in flight and returns to the initial data and idle.

dispose(): void

Aborts work in flight and releases the state from its scope, without waiting for the scope itself. Idempotent.

Disposal aborts but does not announce: subscribers are not notified, because they are being disposed alongside it.

readonly disposed: boolean

Whether the async state has been disposed.

AsyncSnapshot

status: 'idle' | 'loading' | 'refreshing' | 'success' | 'error'

One of idle, loading, refreshing, success, or error. refreshing means existing data is retained while a new request runs.

data: T | null

The last successful value, retained across a refresh and across a failure.

error: unknown

The failure, when the status is error.

Declarative structure

Trees

tree() builds a detached hierarchy from a configuration object. Text is always text; reactive values are accepted for text, attributes, classes, and children.

TreeConfig

tag: K

The tag to create. Required.

text?: unknown | Readable<unknown>

Text content, or a readable for reactive text. Always written as a text node; markup is never parsed.

attributes?: Record<string, unknown | Readable<unknown>>

Attributes to set. A value may be a readable, which binds the attribute.

{ tag: 'button', attributes: { type: 'button', disabled: busy } }

class?: string | readonly string[] | Record<string, Readable<unknown> | boolean>

A class name, an array of them, or a map of name to readable or boolean, which binds each class.

{ tag: 'div', class: { panel: true, 'is-busy': busy } }

properties?: Record<string, unknown>

Native properties written verbatim.

This is a deliberate escape hatch, not a text path: properties: { innerHTML } parses markup exactly as the DOM would. Never pass untrusted input through it.

on?: Record<string, EventListener | { handler: EventListener; options?: AddEventListenerOptions | boolean }>

An event map. A value may be a handler, or { handler, options } for listener options.

children?: readonly TreeChild[] | TreeList<any>

An array of child configurations, elements, nodes, or strings — or a reactive list, which renders the container's entire contents.

{
    tag: 'ul',
    children: {
        each: rows,
        key: row => row.id,
        render: row => sculptor.tree({ tag: 'li', text: row.label }),
        update: (element, row) => element.setText(row.label)
    }
}

ref?: string

Names this node in the refs object given at the root, so it can be reached without a selector.

refs?: Record<string, DomElement>

Root level only: an object filled with every node in the tree that declares a ref.

let refs = {};
sculptor.tree({ tag: 'form', refs, children: [{ tag: 'input', ref: 'email' }] });
refs.email.setValue('someone@example.com');

TreeList

each: Readable<readonly T[]>

The readable holding the collection.

key?: (item: T, index: number) => unknown

Optional. With a key the list is keyed and rows keep their identity; without one, rows are replaced.

render: (item: T, index: number) => DomElement

Builds a row.

update?: (element: DomElement, item: T, index: number) => void

Applies changed data to a reused row.

Large collections

Virtual lists

Only the visible range plus overscan exists in the DOM, while a spacer of the full collection height keeps the scrollbar honest.

VirtualListOptions

rowHeight: number

Fixed row height in pixels. Required, and the basis for every range calculation.

render(item: T, index: number): DomElement | VirtualRow

Builds a row from an item. May return a DomElement or a reusable VirtualRow.

overscan?: number

Extra rows kept above and below the viewport, smoothing fast scrolling. Defaults to 4.

key?(item: T, index: number): unknown

Stable identity per item, enabling row reuse across updates. Duplicates are rejected before any DOM change.

aria?: boolean

Set false to omit the role and position metadata when you are supplying your own.

VirtualRow

root: DomElement

The row element.

update?(item: unknown, index: number): void

Applies a different item to a reused row.

Not called while the row holds focus, so a refresh cannot overwrite a half-typed value.

dispose?(): void

Releases anything the row owns beyond its element, called when the row leaves the mounted range.

VirtualListStatus

readonly rendering: boolean

Whether a pass is queued.

readonly start: number

First mounted index, including overscan.

readonly end: number

One past the last mounted index.

readonly mounted: number

How many rows exist in the DOM — the number to watch against total.

readonly total: number

Size of the whole collection.

VirtualScrollOptions

align?: 'start' | 'center' | 'end' | 'nearest'

start, center, end, or nearest. Defaults to nearest.

Routing

Router

One route mounted at a time, each view in its own scope, with the previous view disposed on every change.

Router

current: Readable<RouteSnapshot>

A readable snapshot of the active route, for titles, navigation state, and derived values.

navigate(path: string): void

Navigates by pushState, or by fragment in hash mode.

Throws. TypeError for an empty path.

replace(path: string): void

As navigate, replacing the current history entry.

stop(): void

Stops routing, removes the listener, and disposes the mounted view and its scope. Idempotent.

readonly stopped: boolean

Whether the router has been stopped.

RouteSnapshot

path: string

The matched path.

route: string | null

The pattern that matched, or null when nothing did.

params: Record<string, string>

Decoded parameters. A * route provides rest.

* is a whole-path wildcard, so '*' keeps the leading slash in rest while '/*' captures only the remainder.

RouteViewSnapshot

scope: DisposalScope

The scope the router created for this view. Ask scope.disposed in an asynchronous continuation to find out whether the route is still on screen.

'/posts/:slug': ({ params, scope }) => {
    let post = sculptor.signal(null);
    load(params.slug).then(value => {
        if (scope.disposed) return;   // the reader navigated away
        post.set(value);
    });
    return view(post);
}

RouterOptions

parent?: string | Node | DomElement

The outlet the active view is mounted into. Defaults to document.body.

hash?: boolean

Route on the URL fragment instead of the path, for static hosting and extensions that cannot rewrite server paths.

Composition and lifetime

Components, scopes, and contexts

A component is a factory with a disposal scope. A scope owns whatever is created inside it. A context passes values down without threading them through props.

ComponentDefinition

root: DomElement | Node

The element the component renders. Required.

api?: A

Methods the parent may call, kept separate from the DOM so a component exposes behaviour rather than internals.

dispose?: () => void

Extra cleanup, run with the component’s scope.

ComponentInstance

root: DomElement

The rendered element.

api: A

Whatever the definition exposed.

scope: DisposalScope

The disposal scope owning everything the factory created.

context: Context

The context the instance was created with.

name: string

The name from options, or the factory’s name. Used in diagnostics.

createdAt?: string

A creation stack, captured only on a development runtime, for tracing a leaked instance back to its origin.

dispose(): void

Disposes the scope, and with it the root and everything created inside the factory. Idempotent.

readonly disposed: boolean

Whether the instance has been disposed.

DisposalScope

track<T extends () => unknown>(cleanup: T): T

Registers custom cleanup, for resources the library does not own itself.

Returns. The cleanup function.

Throws. TypeError without a function.

scope.track(() => clearInterval(timer));

run<T>(callback: () => T): T

Runs a callback with this scope active, so everything created inside belongs to it.

Returns. Whatever the callback returns.

Throws. Error if the scope is already disposed.

dispose(): void

Releases everything in reverse order of creation, so a subscription made after the element it writes into is released first. Every cleanup is attempted even when some fail, and multiple failures are reported together as an AggregateError.

readonly disposed: boolean

Whether the scope has been disposed.

Context

get<T>(key: ContextKey<T>, fallback?: T): T

Reads a value, falling back through parent contexts and then to the supplied default.

Returns. The value, or the fallback.

has(key: symbol): boolean

Whether the key resolves here or in a parent.

Returns. boolean.

set<T>(key: ContextKey<T>, value: T): this

Sets a value on this context.

Returns. The context.

delete(key: symbol): boolean

Removes a local value, after which the key resolves through the parent again.

Returns. boolean.

child(initial?: Map<symbol, unknown> | Record<PropertyKey, unknown> | null): Context

Creates a child context that inherits from this one and may override any key.

Returns. The child Context.
