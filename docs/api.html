Complete API reference

Every public operation, in one place.

Signatures below show the common JavaScript form. TypeScript declarations ship with the package and infer native element types, component props, component APIs, stores, contexts, and events.

Most mutating element methods return the same DomElement for chaining. Programmer errors throw. Methods named try* catch failures and return null; see the mounting note below for the possible DOM side effect.

Runtime and ownership

DomSculptor

new DomSculptor(options?)

Creates an isolated scheduler, scope stack, and element registry. Options support development and onWarning. Create separate runtimes when interfaces need isolated flushing and diagnostics.

create(tag, parent?, callback?)

Creates and returns a chainable element synchronously. Without a parent it stays detached. With a selector, native Node, or DomElement parent, it mounts immediately.

createProgressively(tag, parent, callback?)

Creates and returns a chainable element immediately while progressively mounting calls for the same parent. The first element mounts immediately and later elements mount one per animation frame, or one per timer turn when animation frames are unavailable. The callback runs before return, including while an element is waiting in the parent queue, so attributes, events, bindings, children, and lifecycle hooks can be configured normally. Disposing a queued element prevents its later insertion.

createDetached(tag, callback?)

Explicit detached alias for create(tag).

createIn(parent, tag, callback?)

Creates and immediately inserts an element into a required parent.

mount(value, parent) / tryMount(value, parent)

Mounts a live element or component. mount throws for invalid input, a missing parent, or a failing mount hook. tryMount catches the failure and returns null. Because insertion happens before mount hooks run, a hook failure can leave the value mounted even when tryMount returns null.

unmount(value)

Temporarily detaches without disposing listeners, bindings, state, or identity. The same value can be mounted again.

wrap(selectorOrNode) / tryWrap(...)

Gets the stable wrapper for existing DOM. Strict wrapping throws when no node is found; the try form returns null.

adopt(node)

Takes managed ownership of existing native markup so lifecycle and cleanup work like DOMSculptor-created elements.

tree(config)

Creates a detached hierarchy from tag, text, attributes, class, properties, on, and recursive children. Text stays text; raw HTML is not interpreted. Pass a refs object at the root and ref on any node to collect named nodes as the tree is built. Attribute values may be signals, class accepts a map of class names to signals or booleans, and children accepts { each, key?, render, update? } to render the container's contents as a reactive list.

rendering

A read-only boolean describing whether any createProgressively() cycle is active. It becomes true for the first call even though that element mounts immediately, and returns to false after every parent queue finishes its scheduled frame or timer callback. Separate parents have separate queues.

DOM wrappers

DomElement

Native access

element.html is the native node until disposal, then null. children is a frozen snapshot of managed child wrappers.

Text and value

setText(value), text(readable), getValue(), and setValue(value). text() appends one targeted text node, updates it through the runtime scheduler, and unsubscribes when the element is disposed. Transform a signal with computed() before passing it when derived text is required.

Attributes

attribute.set(name, value), attribute.set(object), remove, get, and has. attr(name, readable) creates a reactive binding: null and false remove the attribute, while true writes an empty attribute.

Classes and styles

class.add/remove/toggle/contains, classToggle (one class, or a map of class names to signals or booleans), setStyle, and reactive styleValue.

Visibility and focus

hide(), show(), focus(options?), blur(), and isFocused(). Showing restores the previous inline display value.

Children

child.append, prepend, create, replace, clear, and remove. Accepted children are wrappers, native nodes, and strings. append and prepend return the element that was added, so a structure can be built downwards without a temporary for every level; a raw node or string has no wrapper to return, so those return the container.

Traversal and placement

parent(), closest(selector), childrenOf(), child.find, findAll, before, and after.

Events

on(event, handler, options?), event maps, delegated on(event, selector, handler), once, and off. Disposal releases retained callbacks.

Lifecycle

onMount, onUnmount, onDispose, and compatibility alias onRemove. Unmount is temporary; dispose is permanent. Disposal detaches the node first and then discards the subtree, so a hook sees the subtree already out of the document; only the element disposal started at has a null parentNode.

dispose()

Runs child-first cleanup once, removes DOM, releases bindings and events, and nulls the native reference. Multiple cleanup failures are reported together with AggregateError.

Fine-grained reactivity

Signals, computed values, and effects

const count = sculptor.signal(0);
const doubled = sculptor.computed(() => count.get() * 2, [count]);
const stop = sculptor.effect(() => title.setText(doubled.get()), [doubled]);

count.set(1);
count.update(value => value + 1);
sculptor.flush();

stop();
doubled.dispose();
count.dispose();

signal(initial) / state(initial)

Returns state with get, set, update, subscribe, bindings, lists, and dispose. Equal values are skipped.

subscribe(callback, options?)

Returns an unsubscribe function. Use immediate: true for initial delivery or pass an AbortSignal for automatic removal.

Bindings

bindText, bindValue, bindAttribute, bindClass, bindStyle, bindVisible, bindHidden, and bindProperty. Element disposal removes the binding. bindVisible toggles inline display through show and hide; bindHidden sets the native hidden property and leaves inline styles alone.

bind(element, options?) / sync(...)

Two-way native form binding for text, numbers, checkboxes, radio groups, and selects. Options provide event, parse, format, custom get/set, grouped values, and multiple selection.

computed(compute, dependencies?)

Creates a cached read-only value. Omit the dependency list to track the signals the computation reads, including branches it stops reading; pass one to pin dependencies, or pass an empty list to evaluate once. Unchanged results do not notify subscribers.

effect(run, dependencies?)

Runs immediately, reruns after dependency changes, and invokes the previous returned cleanup before rerunning. Dependencies are tracked automatically unless a list is supplied. The returned function stops the effect.

batch(callback) / flush()

Batch groups scheduled work. Values change immediately; DOM jobs are deduplicated. flush completes pending work synchronously and is useful in tests.

list(container, options)

Keyed mode uses key, render, and optional update. Stable keys move existing nodes and preserve focus. Duplicate keys throw before changing the DOM.

Structured state

Stores

store(initial) and data(initial) are aliases. Use get(key?), set(key, value), bulk set(object), update, has, delete, and signal(key). Observe one property with onChange, everything with onAnyChange, and release observers with the returned unsubscribe function, offChange, an abort signal, or dispose.

Large collections

Virtual lists

virtualList(items, container, options) keeps only the visible range and a configurable overscan in the DOM while a spacer represents the full collection height. Options are rowHeight (required), render (required), overscan, key, and aria. A render may return a DomElement or a reusable row { root, update?, dispose? }; reused rows must read their item from update(). Companion methods are updateVirtualList, scrollVirtualList (by index or by key, aligned start, center, end, or nearest, returning false for unreachable targets), virtualListStatus (a frozen snapshot of rendering, start, end, mounted, and total), and disposeVirtualList. Scroll and resize collapse into one pass per animation frame, duplicate keys are rejected before any DOM change, and a failing render rolls back the rows it created.

Navigation

Routing

router(routes, options?) maps path patterns to view functions, mounts one match at a time, and disposes the previous view on every change. Patterns accept :name parameters and a * catch-all, and each view receives { path, route, params, scope }. Each view runs inside its own disposal scope, so the signals, effects, and subscriptions it creates are released when the route changes, and scope.disposed tells an asynchronous continuation whether its route is still on screen. A view may return a DomElement or a component instance. Use navigate and replace for programmatic navigation, bind to the readable current signal for derived state, and stop() to detach. Back and forward work through popstate; pass { hash: true } to route on the URL fragment. The runtime owns the router, so sculptor.dispose() stops it.

Ownership

Runtime disposal

sculptor.dispose() releases everything the runtime created that no explicit scope already owns: signals, computed values, effects, stores, async state, and elements. It is idempotent and reports through sculptor.disposed. Nodes created by the runtime are removed; nodes adopted through wrap() or adopt() remain in the document with only their listeners and bindings released. Disposing a resource directly releases its ownership entry, so repeated create/dispose cycles do not accumulate cleanups.

Composition and lifetime

Components, scopes, contexts, and boundaries

component(factory, options?)

Returns a factory receiving props and context. Return a root wrapper/node or { root, api, dispose }. Instances expose root, api, scope, context, name, and dispose.

createScope()

scope.run(callback) automatically owns resources created inside it. track(cleanup) adds custom teardown. dispose runs cleanup in reverse order.

Context

Create typed keys with createContextKey. Contexts support get, has, set, delete, and inherited child contexts.

when(condition, branch, options?)

Switches conditional DOM. Options support fallback, preserved branches, stop-time disposal, and direct mounting with parent. The returned function stops rendering.

errorBoundary(factory, fallback)

Catches component-construction failures, cleans the failed scope, and creates deterministic fallback UI.

Development diagnostics

createDevSculptor({ onWarning }) reports ownership, invalid usage, cleanup, duplicate-key, and leak diagnostics. reportLeaks() returns the active component count.

Cancellable work

Async state

asyncState(initialData?) exposes snapshots with status, data, and error. Status is idle, loading, refreshing, success, or error. Run work with run(({ signal }) => task); later runs abort earlier work by default. Use retry, cancel, and reset for explicit control. run and retry resolve with the resulting snapshot and never reject, so a failed or aborted run needs no handler of its own.

Main package entry

Named convenience exports

The main package exports signal, state, store, data, computed, effect, batch, flush, tree, when, mount, unmount, asyncState, errorBoundary, and createDevSculptor. These functions use one shared default DomSculptor instance. Import the default constructor and create an instance when an interface needs isolated scheduling, scopes, ownership diagnostics, or flushing.

DomElement and DevDomSculptor are also exported. createTestHarness and createLazyComponent are available from the main entry for compatibility and through the focused domsculptor/testing and domsculptor/lazy package subpaths.

Optional entry

domsculptor/testing

createTestHarness(parent?, options?) creates an isolated development runtime and fixture root. Use mount, deterministic flush, assertClean, captured warnings, and idempotent dispose. This subpath resolves to the same src/index.js runtime and uses a focused declaration file.

Optional entry

domsculptor/lazy

createLazyComponent(sculptor, loader, options?) converts a dynamic loader into a component factory. The loader receives signal, props, and context. Options configure name, wrapper tag, loading UI, error UI, and onError. Its API exposes a reactive loading/success/error status, and disposal aborts loading and disposes the loaded child. This subpath resolves to the same src/index.js runtime and uses a focused declaration file.

Failure and cleanup rules

Errors stay visible.

Invalid API input throws TypeError. Missing strict selectors and invalid mounts throw. Search operations and tryWrap/tryMount may return null. Subscriber notification continues across failures before rethrowing; multiple cleanup failures become AggregateError.
